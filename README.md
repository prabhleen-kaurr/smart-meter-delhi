# Smart Delhi Meter (ZEDF)

A comprehensive IoT-based energy monitoring solution designed to provide real-time insights into electricity consumption. ZEDF (Zero Emission Digital Framework) focuses on high-precision energy analytics, intelligent monitoring, and a seamless user experience through a modern MERN-based architecture.

---

## Overview

Smart Delhi Meter (ZEDF) is an IoT-based smart energy monitoring platform that enables users to track and analyze electricity consumption in real time. The system combines cloud-based storage, live analytics, and an interactive dashboard to help users monitor usage patterns, detect abnormal power consumption, and improve energy efficiency.

---

## Features

### Real-Time Monitoring

* Tracks voltage, current, power, and energy consumption in real time
* Low-latency updates for accurate monitoring

### Interactive Dashboard

* Responsive web dashboard built using the MERN stack
* Clean and modern user interface with Tailwind CSS

### Data Visualization

* Interactive graphs and analytics using Chart.js
* Displays:

  * Historical energy consumption
  * Peak load timings
  * Usage trends and comparisons

### Alert System

* Detects unusual power spikes and overload conditions
* Provides instant notifications and alerts

### Cloud Integration

* Secure cloud-based data storage
* Remote monitoring access from any connected device

# Installation and Setup

## Clone the Repository

```bash
git clone https://github.com/username/smart-delhi-meter-zedf.git
cd smart-delhi-meter-zedf
```

---

## Backend Setup

Navigate to the server directory:

```bash
cd server
```

Install dependencies:

```bash
npm install
```

Start the backend server:

```bash
npm start
```

---

## Frontend Setup

Open a new terminal and navigate to the client directory:

```bash
cd client
```

Install dependencies:

```bash
npm install
```

Start the frontend application:

```bash
npm start
```
